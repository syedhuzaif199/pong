# v1.4.0 — Controls, Resilience & Network Polish

## Scope

- unified keyboard / controller / touch paddle input
- Android hold + swipe controls with identical fixed paddle physics
- Android Back/MENU pause UX and persistent control affordances
- 10-second transient disconnect grace with automatic recovery
- Android background/foreground lifecycle integration
- RTT jitter, state-arrival jitter, packet-loss, and stream-rate diagnostics
- RTT-aware bounded client extrapolation and jitter-aware correction
- explicit Internet connection-phase UI
- Android launcher/release metadata and optional signed APK+AAB CI
- desktop application icons: embedded Windows PE icon, macOS `.icns` in `Pong.app`, Linux freedesktop launcher/icon packaging

## Compatibility

Gameplay protocol remains **4**. Discovery remains **1**. Rendezvous remains **1**. No TURN/relay is added.
