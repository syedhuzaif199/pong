# v1.5.0 — Local Play

v1.5 is the first feature-focused release after the networking/mobile foundation work in v1.3-v1.4.

## New modes

### VS CPU

- Available on desktop and Android.
- Easy / Normal / Hard CPU difficulty.
- The CPU predicts wall-reflected ball intercepts, but reacts on a difficulty-dependent cadence and deliberately carries aim error.
- The CPU is fair: `step_host_game` still applies exactly the configured `paddle_speed`; difficulty never grants a faster paddle.
- Player controls remain the normal platform controls: W/S or arrows, controller, or Android touch/swipe.

### Local 2P

Desktop:
- Player 1: W/S or gamepad 0.
- Player 2: arrow keys or gamepad 1.

Android:
- Left half of the screen controls Player 1.
- Right half controls Player 2.
- Two simultaneous touches can move both paddles.
- Each half uses the familiar upper/lower hold zones.

## Local match flow

- Dedicated Local Play and Local Match Setup screens.
- Winning score, ball speed, and paddle speed are configurable before the match.
- CPU difficulty is remembered in local preferences.
- Local pause freezes simulation.
- Local game-over offers an immediate rematch.
- Network diagnostics and reconnect UI are suppressed for local games.

## Compatibility

- Application version: 1.5.0
- Gameplay protocol: 4 (unchanged)
- Discovery protocol: 1 (unchanged)
- Rendezvous protocol: 1 (unchanged)

No packet formats changed in v1.5. The new modes do not use the network transport.
