# v1.6.0 — Competitive Play

v1.6 starts from the clean v1.5 Local Play codebase and focuses on match depth rather than presentation changes.

## Competitive match rules

- Best-of 1, 3, 5, or 7 games.
- Optional win-by-two scoring within each game.
- Optional paddle spin: actual paddle velocity at impact adds controlled vertical velocity to the ball.
- Optional ball acceleration: preserves the classic accelerating-rally behavior when enabled; disabling it keeps horizontal ball speed bounded near the serve speed.
- The CPU never exceeds the configured paddle-speed rule; spin uses the same physical paddle velocity as human players.

## Match flow

- Winning a game no longer necessarily ends the match.
- Non-final games pause briefly on the completed score, then automatically start the next countdown.
- The HUD shows games won and the current game number.
- Rematch starts a fresh best-of set only after the entire match is complete.

## Match summary

The final screen shows:

- games won,
- total points,
- each completed game's score,
- longest rally (paddle returns),
- fastest observed ball speed,
- elapsed match time,
- average RTT for online play.

## Networking

- Gameplay protocol: **5** (bumped from 4 because competitive rules and match state are synchronized).
- Discovery protocol: **1**.
- Rendezvous protocol: **1**.
- Host authority, direct UDP, reconnect grace, LAN discovery, STUN, and rendezvous architecture are unchanged.
